2.Apa itu Repository? Repository atau Repo ialah storage fundamental di github dimana kalian menyimpan kode, files, dokumentasi,untuk 1 project spesifik, lengkap dengan history revisi dari perubahan yang pernah dibuat memungkinkan banyak collaborators untuk bekerja secara bersamaan di dalam 1 codebase yang sama menggunakan git version control, dan beberapa fitur seperti branches, commits, pull requests, dan issue tracking.

3.Repository di GitHub berfungsi sebagai tempat penyimpanan utama untuk seluruh file proyek, seperti source code, gambar, dan dokumentasi, yang terorganisir dalam struktur folder cloud digital.  Kegunaannya diantarany seperti Version Control, yaitu mencatat setiap commit sehingga collaborators dapat melihat history revisi, mengidentifikasi siapa yang mengubah apa, dan mengembalikan proyek ke versi sebelumnya jika terjadi human error. Github juga memungkinkan banyak developer bekerja pada proyek yang sama secara bersamaan melalui fitur seperti branch, pull request, dan merge tanpa merusak kode utama. Github juga dapat menyimpan data proyek secara aman di server online, sehingga data tetap tersedia dan dapat diakses dari device mana pun, mengurangi risiko kehilangan data akibat kerusakan perangkat lokal.

git add --all / git add -A: Menambahkan seluruh file (baru, dimodifikasi, dan dihapus) ke staging area.
